# 发布运营规则模板

> 公开版只提供发布流程和记录模板。平台优先级、发布时间、话题策略和转化动作需要用户自己填写。

## 发布前检查

内容从 OPC System 出来后，发布前过一遍：

1. 标题是否足够明确：用户一眼知道看什么。
2. 开头是否能独立工作：不依赖封面和标题。
3. 封面 / 首图是否承载核心信息。
4. 是否需要针对不同平台做格式适配。
5. 是否存在敏感词、绝对化表达、结果承诺或站外引流风险。
6. 是否记录了发布后的复盘落点。

## 平台配置

按你的实际阵地填写。

```markdown
## [平台名称]

- 内容形式：
- 标题规则：
- 封面 / 首图规则：
- 推荐发布时间：
- 话题标签规则：
- 互动策略：
- 不要做什么：
```

## 发布后动作

1. 前 30 分钟：关注首批互动，记录高质量评论。
2. 前 2 小时：观察初始数据，判断标题、封面和开头是否有效。
3. 24 小时后：记录数据快照，判断是否需要追加运营。
4. 数据好：考虑跨平台分发、做续集、深挖同主题。
5. 数据差：不急着删，先分析原因，记录到复盘。
