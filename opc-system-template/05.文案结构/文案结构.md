# 文案结构

## 1. 观点输出型

适合：有明确非共识判断。

结构：

1. 直接抛判断。
2. 说大多数人怎么误解。
3. 给出你的证据。
4. 总结成一个方法论。

## 2. 教程演示型

适合：工具、流程、方法教学。

结构：

1. 场景痛点。
2. 展示结果。
3. 拆步骤。
4. 提醒卡点。
5. 给下一步动作。

## 3. 案例拆解型

适合：爆款、账号、产品、商业案例。

结构：

1. 极致结果。
2. 为什么反常识。
3. 五维度拆解。
4. 可迁移方法。
5. 不要照搬的风险。

## 4. 认知升级型

适合：建立新概念或新框架。

结构：

1. 描述一个常见现象。
2. 给这个现象命名。
3. 解释底层原理。
4. 给出判断公式。
5. 给出自查清单。

## 5. 故事驱动型

适合：个人经历、踩坑、转折。

结构：

1. 先给结果或冲突。
2. 回到当时场景。
3. 讲选择和代价。
4. 提炼认知变化。
5. 给用户可用的结论。
