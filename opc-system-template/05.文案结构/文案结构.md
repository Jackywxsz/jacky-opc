# 文案结构框架使用说明书

> 这个文件夹存放所有验证过的文案结构。每个结构按「来源 → 适用场景 → 骨架 → 使用要点」组织。

## 怎么用这个文件夹

1. **按对标/博主建子文件夹** — 每个值得学习的博主一个文件夹，放他们的结构拆解
2. **通用结构放根目录** — 不属于某个博主的通用框架直接放在这里
3. **每个结构标注效果** — 用过的结构在 `框架效果数据.md` 里记录实际效果

## 六种基础结构

| 类型 | 适合场景 | 核心骨架 |
|------|---------|---------|
| 观点输出 | 认知升级、行业判断 | 反常识判断 → 递进拆解 → 认知框架 |
| 教程演示 | 工具教学、实操指南 | 展示结果 → 核心步骤 → 使用场景 |
| 对比分析 | 横评、方案对比 | 对比结论 → 逐维度比 → 选择建议 |
| 故事驱动 | 个人经历、案例拆解 | 高潮/反转 → 完整叙事 → 提炼认知 |
| 认知升级 | 给现象命名、建框架 | 常见现象 → 命名+拆解 → 框架怎么用 |
| 案例拆解 | 爆款分析、行业事件 | 亮点/争议 → 多维拆解 → 我怎么用 |

## 金字塔通用逻辑

所有结构的底层：**核心判断 → 理由 → 证据**

## 子文件夹命名规则

- 按博主/来源命名：`来源A/`、`来源B/`、`来源C/`
- 每个文件夹内的文件：`博主名-框架名.md`
