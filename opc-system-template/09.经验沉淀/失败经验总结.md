# 失败经验总结模板

> 公开版只保留沉淀结构，不放原系统里的具体经验清单。

失败经验不是为了记录情绪，而是把一次踩坑变成下一次发布前的检查项。

## 单条失败经验

```markdown
## YYYY-MM-DD - [失败主题]

- 发生在哪个平台 / 场景：
- 当时做了什么：
- 结果为什么不好：
- 根因判断：
- 下次避免方式：
- 可转成的检查项：
```
