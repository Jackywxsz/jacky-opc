# OPC System 文件夹构建参考

这是从一套真实运行中的 OPC System 脱敏导出的公开版。它保留了原系统的文件夹结构、方法论模板、选题库生成方式、开篇模板、脚本落点和复盘闭环；去掉了完整选题资产、完整观点资产、个人经历、私有对标笔记、未发布稿件、真实数据和本机路径。

使用方式：

1. 把整个 `opc-system-template/` 复制到你的 Obsidian 或普通文件夹。
2. 重命名为你自己的 `OPC System`。
3. 先填 `01.用户画像`、`02.对标账号`、`03.我的上下文`。
4. 再用 `04.选题决策` 的生成模板，逐步建立自己的 100 条谜题和 100 条非共识。
5. 写完、发布后，把数据复盘写回 `08.数据反馈` 和 `09.经验沉淀`。

最重要的原则：不要只复制 skill，要复制“生产体系”。
