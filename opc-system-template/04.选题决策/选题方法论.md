# 选题方法论

## 选题决策三问

拿到任何选题，先回答：

1. **人群关心吗？** — 不是你觉得重要，是你在 `01.用户画像/` 里定义的目标受众觉得重要
2. **我有独特视角吗？** — 亲测、踩坑、真实案例、反常识判断，缺一不可
3. **现在讲有时效性吗？** — 新工具、政策变化、热点事件窗口

三个都是 → 立刻做
两个是 → 值得做
只有一个 → 再想想，除非角度极其独特

## 选题分级

- **S 级**：三问全是 + 强时效 → 48 小时内出
- **A 级**：两问是 + 有独特视角 → 本周排期
- **B 级**：一问是 + 角度有潜力 → 放入选题池观察
- **淘汰**：和定位无关、没有新角度、已被讲烂

## 方向讨论框架

确认选题后，从以下维度给出 2-3 个方向：

### 谜题类型（按强弱排序）

| 类型 | 核心驱动力 | 适合场景 |
|------|-----------|---------|
| **WOW** | 极致案例让大脑预测宕机 | 有极端数据/人物/结果时首选 |
| **WHY 型** | 因果好奇 | 反常识事实、案例拆解 |
| **HOW 型** | 方法好奇 | 教程、干货、方法论 |
| **WHAT IF 型** | 实验好奇 | 假设、预测、挑战类 |

### WOW 的素材来源——极致的六种形式
- 坚持的极致 / 逆境的极致 / 能力的极致 / 情感的极致 / 品格的极致 / 忠诚的极致

### 每个方向必须包含

- **谜题类型**：用 HOW / WHY / WHAT IF / WOW 哪种切入？
- **极致素材**：有没有极端案例、反常识数据可以制造 WOW？
- **核心判断**：一句话，这篇内容想让读者带走什么认知？
- **认知框架**：能给这个判断起个名字吗？（像"谜题""极致"这样的概念）
- 需要哪些证据或案例支撑

## 呈现策略

确认方向后，选择呈现方式：
- **认知升级型**：给概念命名 + 建框架
- **案例驱动型**：用真实案例推导结论
- **实操演示型**：手把手展示过程和结果

## 筛选标准

选题最终通过的标准：
- 能用一句话说清楚核心判断
- 有至少一个让人"哦？"的信息点
- 不和近期已发布内容重复角度
- 有足够素材支撑（案例、数据、经验）
