# 100 条非共识

非共识不是为了唱反调，而是把你真正相信、又和大众直觉不同的判断沉淀下来。

## 写法

```text
大多数人以为 A，其实真正重要的是 B。
```

## 10 条示例

1. Skill 不是护城河，生产体系才是。
2. 内容创作者最缺的不是写作速度，而是选题判断。
3. AI 写作做轻之后，前置思考和后置复盘反而更值钱。
4. 对标不是找人抄，而是找已经被验证过的用户需求。
5. 好开头不是话术问题，而是问题本身有没有张力。
6. 爆款不是单点技巧，而是一整套反馈系统的外显结果。
7. 个人 IP 最难复制的不是观点，而是观点背后的经历和证据链。
8. 写得像真人，不是加语气词，而是有真实判断和取舍。
9. 选题池不是灵感仓库，而是一个决策系统。
10. 数据复盘的目标不是解释过去，而是改变下一次动作。
