# 100 条非共识生成模板

> 公开版只提供生成方法和空白模板，不提供原系统里的完整观点资产。

非共识不是为了故意唱反调，而是把你长期观察到、但目标用户还没意识到的因果链说清楚。它应该能落到行动，否则只是情绪口号。

## 好非共识的标准

| 维度 | 检查问题 |
| --- | --- |
| 有对象 | 这句话是说给哪类人听的？ |
| 有反差 | 它反对了哪种常见认知？ |
| 有因果 | 为什么你认为常见认知不够准确？ |
| 可行动 | 用户听完之后能改变什么动作？ |
| 可验证 | 后续能不能通过数据、案例或复盘验证？ |

## 生成步骤

1. 写出常见认知：大多数人以为 A。
2. 写出你的观察：但我发现 B 更关键。
3. 写出底层原因：因为 C。
4. 写出行动指向：所以应该先做 D。
5. 压缩成一句有判断力的话。

## 句式模板

```text
[目标用户] 真正缺的不是 [表层问题]，而是 [底层问题]。
大多数人以为 [常见认知]，但真正决定结果的是 [关键变量]。
[某个动作] 不是目的，能否 [更底层动作] 才是关键。
越想 [常见追求]，越要先解决 [被忽视的前提]。
```

## 少量示范

这些只是句式示范，不是可直接复制的私有观点库。

1. [某系统] 的核心不是 [常见指标]，而是 [更底层的稳定机制]。
2. [常见能力] 不是护城河，能持续 [复盘动作] 的 [生产体系] 才是。
3. [某素材库] 不是 [表层用途]，而是未来 [长期资产] 的原材料库。
4. [高级动作] 之前，先把 [基础流程] 跑通。
5. 好 [内容/产品/服务] 不是 [表层特征]，而是 [底层判断]。
