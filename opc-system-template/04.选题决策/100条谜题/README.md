# 100 条谜题

谜题不是标题库，而是你的长期问题库。

## 写法

每条谜题建议包含：

- 类型：HOW / WHY / WHAT IF / WOW
- 问题：
- 对应用户痛点：
- 可用素材：
- 优先级：

## 10 条示例

1. `WHY`：为什么很多人学了很多 AI 工具，内容生产反而更慢？
2. `HOW`：如何让 AI 写作不再每次都从零解释背景？
3. `WOW`：一个文件夹系统，为什么可能比一个复杂 prompt 更有价值？
4. `WHAT IF`：如果每条内容发布后都反哺下一条选题，会发生什么？
5. `WHY`：为什么收藏高但转粉低，说明内容选题可能跑偏了？
6. `HOW`：如何用对标账号拆出自己的选题池？
7. `WHY`：为什么开头写不好，通常不是文案问题，而是选题问题？
8. `HOW`：如何把一次失败发布沉淀成下一次的选题策略？
9. `WOW`：一个非技术创作者，如何用文件夹搭出自己的内容 Agent？
10. `WHAT IF`：如果把用户评论当作选题数据库，而不是互动数据呢？
