# 复盘沉淀方法

## 什么时候复盘

- 每条内容发布 48 小时后：看初始数据
- 每条内容发布 7 天后：看最终数据
- 每月底：月度整体复盘
- 出现异常数据时（特别好或特别差）：立刻复盘

## 单条内容复盘

### 数据记录
- 平台、发布时间
- 播放量 / 阅读量
- 点赞、评论、收藏、转发
- 完播率（如果平台提供）
- 涨粉数

### 分析维度

1. 选题是否选对了？
   - 目标人群是否关心这个话题
   - 时效性是否抓住了

2. 开头是否有效？
   - 完播率 / 跳出率能说明问题
   - 前 3 秒是否留住了人

3. 内容质量如何？
   - 点赞率反映内容价值
   - 评论内容反映用户共鸣点
   - 收藏率反映实用性

4. 标题和封面是否到位？
   - 点击率（如果能看到）
   - 和同期内容对比

### 核心结论
每次复盘必须回答：
- 这条内容做对了什么？（下次继续）
- 这条内容做错了什么？（下次避免）
- 如果重做一次，我会怎么改？

## 月度复盘

### 数据总览
- 本月发布数量（按类型）
- 总播放 / 阅读
- 涨粉数
- 最佳内容 TOP 3
- 最差内容 TOP 3

### 趋势分析
- 哪类选题数据最好？
- 哪种开头类型最有效？
- 哪个平台增长最快？
- 发布频率是否合理？

### 下月调整
- 选题方向要不要调？
- 内容结构要不要优化？
- 发布节奏要不要变？
- 有没有新的对标值得跟？

## 复盘笔记格式

```
# YYYY.MM.DD 复盘

## 复盘对象
[内容标题 / 月度整体]

## 数据
-

## 做对了什么
-

## 做错了什么
-

## 下次怎么改
-
```

## 沉淀规则

- 复盘笔记存到 `08.数据反馈/`
- 月度复盘存到 `08.数据反馈/月度数据分析报告/`
- 命名：`YYYY.MM.DD--复盘主题.md`
- 复盘中发现的选题灵感 → 同步到 `04.选题决策/`
- 复盘中发现的结构优化 → 同步到 `05.文案结构/`
- 复盘中发现的运营经验 → 同步到 `07.发布存档/发布运营规则.md`
- 验证过的方法论 → 同步到 `09.经验沉淀/爆款方法论.md`
