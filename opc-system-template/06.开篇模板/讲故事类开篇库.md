# 讲故事类开篇库

> 适合：个人经历、案例拆解、成长复盘、人物故事
> 核心驱动力：WOW 型 + 情感共鸣（「后来呢？」）

## 开篇公式

### 1. 高潮/反转前置
「[反转结果]。三个月前，我还 [起点状态]。」
→ 反差越大越抓人

### 2. 场景带入
「[具体时间地点]，我盯着 [具体细节]，做了一个决定。」
→ 画面感把人拉进故事

### 3. 极致数据
「[极端数据]。这不是标题党，这是我亲测的结果。」
→ 数据制造 WOW

### 4. 转折点
「一切改变是从 [具体事件] 开始的。」
→ 让人想知道发生了什么

## 极致素材的六种形式

- 坚持的极致 / 逆境的极致 / 能力的极致
- 情感的极致 / 品格的极致 / 忠诚的极致
