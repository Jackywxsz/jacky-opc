# 教知识类开篇库

> 适合：教程、方法论、工具推荐、干货输出
> 核心驱动力：HOW 型好奇（「怎么做到的？」）

## 开篇公式

### 1. 结果前置 + 方法悬念
「我用 [方法/工具] [时间] 做完了 [结果]。」
→ 让人想知道怎么做到的

### 2. 痛点 + 解决方案预告
「你是不是也 [痛点]？我找到了一个办法。」
→ 直接戳中焦虑

### 3. 对比冲击
「以前 [旧做法]，现在 [新做法]，差距是 [具体数字]。」
→ 用数据对比制造冲击

### 4. 反常识方法
「[常见做法] 其实是错的，[正确做法] 才有效。」
→ 打破惯性认知

## 验证过的好开头

> 用过且数据好的开头，每条标注来源和效果
