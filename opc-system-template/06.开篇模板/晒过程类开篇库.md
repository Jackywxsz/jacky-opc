# 晒过程类开篇库

> 适合：实操演示、测评、挑战、记录类内容
> 核心驱动力：WHAT IF 型好奇（「如果这样做会怎样？」）

## 开篇公式

### 1. 实验预告
「我决定用 [工具/方法] 做一个实验，[实验目标]。」
→ 让人想看结果

### 2. 过程高潮前置
「做到第 [N] 步的时候，出了一个我完全没想到的事。」
→ 用悬念锁住注意力

### 3. 挑战型
「给自己一个限制：[限制条件]，看看能做出什么。」
→ 挑战感天然有吸引力

### 4. 翻车预告
「这个工具号称能 [承诺]，我试了一下，结果……」
→ 翻车比成功更吸引人
