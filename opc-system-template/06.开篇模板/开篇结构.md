# 开篇结构

开头不是装饰，而是内容的试用装。

## 好开头公式

```text
好开头 = 话题 + Hook + 可信度
```

## 四类谜题

- HOW：用户想知道怎么做。
- WHY：用户想知道为什么。
- WHAT IF：用户想知道如果这样会怎样。
- WOW：用户被极致事实击中。

## 诊断问题

如果开头不吸引人，先问：

1. 这条内容本身有没有好问题？
2. 有没有反差、冲突或极致结果？
3. 有没有给观众一个继续看的理由？
4. 可信度是否足够？

## 开头自检

- 前 5 秒能独立工作。
- 不依赖标题和封面才能理解。
- 不一上来把答案说完。
- 正文兑现开头承诺。
