# 生产飞轮

Jacky-OPC 的基本单位不是一篇稿子，而是一轮内容生产飞轮。

```text
定位 -> 对标 -> 选题 -> 结构 -> 写作 -> 发布 -> 复盘 -> 沉淀 -> 下一轮选题
```

## 为什么不是从写作开始

大多数 AI 写作流程的问题，是把写作当成核心。它会让你每次都从零开始解释：

- 我是谁
- 写给谁
- 这篇为什么值得写
- 应该参考谁
- 过去哪些内容有效
- 哪些表达风格不适合我

这会让 AI 变成一个“失忆的写稿助手”。Jacky-OPC 的做法是把这些信息沉淀在文件夹里，让 AI 每次开写前先读取上下文。

## 九个文件夹

| 文件夹 | 作用 |
| --- | --- |
| `01.用户画像` | 明确目标用户、痛点、付费动机和行动门槛 |
| `02.对标账号` | 记录值得学习的账号、选题、结构和边界 |
| `03.我的上下文` | 沉淀个人经历、真实观察、口头禅和观点 |
| `04.选题决策` | 用谜题、非共识和目标用户需求筛选选题 |
| `05.文案结构` | 按选题类型选择表达结构 |
| `06.开篇模板` | 用谜题和 WOW 优化前 5 秒 |
| `07.发布存档` | 保存发布文案、平台策略和历史内容 |
| `08.数据反馈` | 记录数据表现和复盘判断 |
| `09.经验沉淀` | 把验证过的规律回流成方法论 |

## 飞轮的复利点

真正产生复利的不是“写得更快”，而是每一轮都留下资产：

- 一条失败内容，留下不能再踩的坑。
- 一条爆款内容，留下可复用的选题角度和结构。
- 一次对标拆解，留下可借鉴的表达方式。
- 一次用户反馈，留下更精准的用户画像。

下一次写作时，AI 读取这些资产，起点就比上一次更高。

## 最小闭环

如果你刚开始，不需要一次填满所有文件夹。先跑最小闭环：

1. 写一版用户画像。
2. 选 3 个对标账号。
3. 写 10 个谜题和 10 个非共识。
4. 产出 1 条内容。
5. 发布后做 1 次复盘。
6. 把复盘结论写回 `09.经验沉淀`。

跑完一轮，再补体系。
