# 对标与拆解

对标不是抄选题，也不是模仿人设。对标的目标是找到可迁移的结构、切口、节奏和用户洞察。

## 五重过滤

选择对标账号时，按五层过滤：

1. 目标用户相似：服务的人群接近。
2. 内容任务相似：同样在教育、转化、信任或传播。
3. 结果已经验证：有稳定数据或清晰商业结果。
4. 风格可以迁移：不是完全依赖个人资源或不可复制身份。
5. 边界清楚：知道学什么，也知道不学什么。

## 拆解五维度

拆一条爆款内容时，看五个维度：

- 选题：它击中了什么人群需求？
- 切口：它为什么不是泛泛而谈？
- 开头：前 5 秒制造了什么好奇？
- 结构：中段如何推进信息？
- 风格：哪些表达让它像真人而不是说明书？

## 可复用资产

每次拆解后，不要只写“这条很厉害”。要沉淀成可复用资产：

- 一个选题角度
- 一个开头句式
- 一个结构框架
- 一个用户痛点
- 一个不能照抄的风险点
