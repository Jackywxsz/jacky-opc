# 复盘与沉淀

复盘不是给内容打分，而是把一次发布转化成下一次选题的输入。

## 单条内容复盘

每条内容发布后，记录四类信息：

1. 基础数据：曝光、点击、观看、完播、互动、收藏、转粉。
2. 做对了什么：选题、开头、结构、案例、发布时间、封面等。
3. 做错了什么：用户没停下来的原因、信息密度问题、表达问题。
4. 下次怎么改：具体到下一条内容怎么调整。

## 复盘三问

```text
做对了什么？
做错了什么？
如果重做一次，我会怎么改？
```

## 沉淀原则

只有经过数据或反馈验证的东西，才进入 `09.经验沉淀`。

- 验证过的结构 -> `爆款方法论.md`
- 反复踩的坑 -> `失败经验总结.md`
- 有价值的概念 -> `核心概念词典.md`
- 新选题线索 -> 回流到 `04.选题决策`

## 月度复盘

每月看 TOP 3 和 BOTTOM 3：

- TOP 3 共同点是什么？
- BOTTOM 3 共同点是什么？
- 哪类用户反馈最多？
- 哪个选题方向应该加码？
- 哪个表达方式应该停止？

月度复盘的输出不是报告，而是下一月的选题策略。
