## 1. 平台规则背景

### 小红书社区公约 2.0（2026年1月上线）

核心价值观：**真诚分享、友好互动、有序经营**，共25条倡导。

三大板块：
- **真诚分享**：AI辅助创作须标识；禁止虚假人设（财富/学历/收入/情感经历）；禁止夸张猎奇标题；限制无资质的医疗、投资等专业领域建议；抵制炫富、色情擦边。
- **友好互动**：尊重不同性别/地域/种族/职业/兴趣；不得利用影响力进行指控或发布煽动性话语；保护未成年人；反对网络暴力。
- **有序经营**：反对恶意竞争、虚假营销与侵权行为；治理高度模板化推广笔记、虚构产品功效、评论区自问自答制造互动假象。

### 审核规模参考（2025年数据）

- 处置涉及制造对立的账号 53.42万，笔记 459.8万篇
- 月均处置相关评论超 800万条
- 用户举报后平均审核时长：30分钟
- 处置虚假笔记 320万篇，虚假人设账号 1万个
- 封禁黑灰产账号超 1000万个

## 3. 限流灰色地带词汇

这些词不一定直接导致删帖，但大概率触发限流（笔记不被推荐到发现页、搜索权重下降）：

### 行业限流等级分类

| 等级 | 行业/话题 | 说明 |
|------|----------|------|
| 重限流 | 电子烟、A货高仿、黄赌毒、医疗、医美、中医、财经（股票/基金）、风水占卜 | 天然限流，需格外谨慎 |
| 轻限流 | 创业、副业、招商、运营、知识付费 | 有一定限流风险 |

## 4. 2025-2026年最新规则变化

### 2025年重大变化

1. **私信导流新规（2025年1月7日）**：禁止在专业号后台自动回复及欢迎语中出现微信号/电话号码，唯一合规路径为官方「私信获客工具」。

2. **交易导流管理细则（2025年3月12日）**：所有交易必须通过小红书商城/直播间购物车/官方留资组件完成。

3. **虚假宣传管理规范升级**：利用后期剪辑/特效/滤镜使产品效果优于实际即构成"效果虚假"违规，首次情节严重即面临商品下架、直播断流。

4. **医美领域"史上最严"**：所有医美商业笔记必须通过聚光平台上传医疗资质；禁止品牌与"医疗专业博主"商业合作；"三品一械"禁止达人/个人买手推广。

### 2026年重大变化

1. **社区公约2.0（2026年1月19日）**：反对制造对立、拒绝虚假人设、反对网暴、保护未成年人、反对虚假营销。

2. **AI内容标注强制化**：使用AI生成图文必须勾选"AI辅助创作"并说明，否则视为违规。AI托管账号将被封禁。

3. **矩阵号治理**：严打矩阵号滥用，技术检测频繁关联的矩阵号并限制曝光，同质化内容降权或封号。

4. **电商类目准入调整（2026年4月）**：个人店禁售成人/儿童教育所有类目及知识付费等虚拟产品；茶、黄金珠宝、奢侈品、手机等高价值类目仅个体店/企业店可售。

5. **算法透明化**：上线算法公示页，每天超50%流量分配给千粉以下创作者。

## 5. 违规处罚机制

### 阶梯处罚
| 阶段 | 处罚 |
|------|------|
| 第一次 | 警告 |
| 第二次 | 账号限流 + 禁言7天 |
| 第三次 | 账号限流 + 禁言30天 |
| 多次/严重 | 封号（品牌资产无法找回） |

### 具体处罚类型
- **笔记层面**：限流（不进推荐池）、搜索屏蔽、内容下架
- **账号层面**：降权、功能限制、禁言、封号
- **商业层面**：商品下架、直播断流、品牌违规分
- **广告法层面**：罚款20万-100万元

### 重要提醒
- 禁言后即使解禁，私信功能也会受到长期限制
- 违规会累计记录，账号被"扣分"后恢复困难
- 小红书审核系统不会具体告知哪些词违规，需自行排查

## 7. 高频踩坑词（创作者反馈）

这些词看起来"无害"，但实际上容易触发审核或限流：

1. **「私信」**：2025年后成为高风险词，容易被反营销系统察觉，评论直接隐藏甚至笔记限流。
2. **「学习」**：在某些场景下也是敏感词（如知识付费相关内容中）。
3. **「黑暗」**「终身」**：在理财/保险文章中可能触发审查。
4. **「正品」**：当作为卖点强调时反而可能触发审核。
5. **竞品代称**：「猫狗」「小破站」「橙色小软件」等代称，平台也能识别。
6. **谐音字/变体**：「薇信」「V我」等变体已被平台检测覆盖，使用后处罚更重。
7. **「回购」「下单」「剁手」**：日常用语但属于营销敏感词。
8. **「天花板」「YYDS」**：本质是绝对化用语的变体。
9. **AI生成内容未标注**：2026年后直接视为违规。
10. **前后对比图**：妆前妆后/几年前几年后的对比，如果暗示产品功效但非真实功效，属于偷换概念。
11. **图片中的二维码/水印**：即便不在文字中提及，图片中出现也会被检测。
12. **过度使用emoji替代敏感词**：平台已升级语义理解，这种规避方式风险越来越高。

### 账号管理踩坑
- 一部手机切换多个账号 → 被判定为营销号/机器号
- 连续发布推广笔记 → 账号降权
- 笔记发布后频繁修改 → 可能触发二次审核
- 用第三方工具批量操作 → 高风险
