# 路径指南

`OPC_ROOT` 指向用户自己的 OPC System 目录。

## 目录结构

| 编号 | 文件夹 | 用途 |
| --- | --- | --- |
| 01 | `01.用户画像/` | 目标用户画像 |
| 02 | `02.对标账号/` | 对标分析 |
| 03 | `03.我的上下文/` | 个人经历和表达风格 |
| 04 | `04.选题决策/` | 谜题、非共识、选题管理 |
| 05 | `05.文案结构/` | 文案结构 |
| 06 | `06.开篇模板/` | 开篇公式库 |
| 07 | `07.发布存档/` | 发布规则和历史内容 |
| 08 | `08.数据反馈/` | 复盘数据 |
| 09 | `09.经验沉淀/` | 方法论和概念词典 |

## 命名规则

- 内容文件：`YYYY.MM.DD--标题.md`
- 对标账号：`账号名.md`
- 复盘笔记：`YYYY.MM.DD--复盘主题.md`

## 常用落点

- 灵感：`04.选题决策/选题管理/选题研究/00-选题记录.md`
- 短视频：`04.选题决策/选题管理/待发布的选题/短视频/`
- 长文：`04.选题决策/选题管理/待发布的选题/公众号+小红书长文/`
- 短帖：`04.选题决策/选题管理/待发布的选题/推文库/`
- 发布后：`07.发布存档/已发布的选题/`
- 复盘：`08.数据反馈/`
- 方法论：`09.经验沉淀/`
